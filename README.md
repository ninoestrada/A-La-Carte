## 📦 Getting Started

### **💾 Installation**
1. Clone the repo
   ```sh
   git clone https://github.com/nestrada2/A-La-Carte.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```

### **▶️ Running the Program**
```
npm run dev
```
